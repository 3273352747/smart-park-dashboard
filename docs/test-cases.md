## 5. 缺陷详情

### BUG-01：新建工单编号显示异常

- **关联用例：** TC-08
- **缺陷现象：** 新建工单后，工单编号未按 `WO-004` 的格式正常递增。
- **根本原因：** `nextOrderNumber` 是 `ref` 对象，生成编号时使用了对象本身，遗漏 `.value`。
- **修复方式：** 将编号生成逻辑改为 `String(nextOrderNumber.value).padStart(3, '0')`。
- **回归结果：** 连续新建多条工单后，编号依次递增且互不重复。

![BUG-01 工单编号异常](BUG-01.png)

### BUG-02：删除一条工单时多条新工单同时消失

- **关联用例：** TC-10
- **缺陷现象：** 删除一条新建工单后，具有相同异常编号的其他工单也被删除。
- **根本原因：** BUG-01 导致多条工单拥有相同 `id`；按 `id` 过滤删除时匹配到了全部重复记录。
- **修复方式：** 修复唯一编号生成逻辑，确保每条工单的 `id` 唯一。
- **回归结果：** 连续创建多条工单后，删除其中任意一条只影响当前记录。

### BUG-03：离开运营总览后页面无法继续切换

- **关联用例：** TC-19
- **缺陷现象：** 从运营总览切换至工单、设备或查询页面时，页面停止响应或出现白屏。
- **根本原因：** `DeviceHealthGauge` 组件卸载时将 ECharts 的 `dispose()` 错写为 `dispoae()`，触发运行时异常。
- **修复方式：** 更正方法名，并在 `onBeforeUnmount` 中移除 `resize` 监听后销毁图表实例。
- **回归结果：** 各业务页面可连续往返切换，控制台不再出现该异常。

### BUG-04：空表单也能提示工单创建成功

- **关联用例：** TC-07
- **缺陷现象：** 未填写必填字段时，页面虽然显示校验提示，但仍继续创建工单并提示成功。
- **根本原因：** 已调用 `formRef.value.validate()`，但没有判断返回的 `valid` 结果，后续创建逻辑仍会执行。
- **修复方式：** 获取校验结果，并在 `valid` 为 `false` 时通过 `return` 立即结束提交函数。
- **回归结果：** 空表单和字段缺失时均无法创建工单；补齐所有必填项后可以正常提交。

### BUG-05：运营总览的近 7 日趋势图不显示

- **关联用例：** TC-22
- **缺陷现象：** 图表容器正常显示，但近 7 日园区能耗折线图区域为空白。
- **根本原因：** 已导入 `EnergyTrendChart`，模板中却使用了错误的组件名称，导致目标图表组件没有挂载。
- **修复方式：** 将模板标签统一为 `<EnergyTrendChart />`，并保留图表初始化及卸载逻辑。
- **回归结果：** 首次进入总览页和路由切换返回后，趋势图均可正常渲染。

### BUG-06：设备类型筛选没有达到预期效果

- **关联用例：** TC-16、TC-17
- **缺陷现象：** 切换设备类型后，指标卡和图表中的设备范围没有正确变化。
- **根本原因：** 类型匹配条件误用了 `selectedRegion.value`，导致类型为“全部”时的判断对象错误。
- **修复方式：** 将类型条件改为判断 `selectedType.value`，并让所有指标和图表统一使用 `filteredOverviewDevices`。
- **回归结果：** 类型筛选、区域筛选及两者组合筛选的统计结果均符合预期。

### BUG-07：增加工单持久化后工单页面白屏

- **关联用例：** TC-23
- **缺陷现象：** 引入 LocalStorage 工单恢复逻辑后，进入工单管理页时页面为空白。
- **根本原因：** 计算下一工单编号时将 `Math.max()` 错写为 `Math,max()`，触发运行时异常。
- **修复方式：** 修正方法调用，并从已有工单编号中计算最大值后加 1。
- **回归结果：** 无缓存时加载默认工单，有有效缓存时恢复缓存工单，页面均可正常显示。

## 6. 开发阶段问题复盘

以下问题主要发生在组件拆分和功能接入阶段，属于编译、路径或响应式写法问题。它们不计入上面的功能缺陷数量，但均已定位并修复。

| 编号 | 问题现象 | 原因 | 处理结果 |
| --- | --- | --- | --- |
| DEV-01 | Vite 无法找到 `DeviceView.vue` | 路由使用了 `../view/`，实际目录为 `../views/` | 修正路由导入路径，页面可正常编译 |
| DEV-02 | `DeviceView` 无法导入 `DeviceList` | 从 `views` 目录错误使用 `./components/` | 改为 `../components/DeviceList.vue` |
| DEV-03 | 编译提示 `StatusFilter` 重复声明 | 同一组件被重复 `import` | 删除重复导入，保留单一组件引用 |
| DEV-04 | 编译提示单文件组件缺少模板或脚本 | `DataQueryView.vue` 创建后内容为空 | 补充 `<script setup>` 和 `<template>` |
| DEV-05 | 设备筛选和统计代码运行异常 | `computed` 拼写错误，且对 `ref` 数组遗漏 `.value` | 修正导入、读取和过滤写法 |
| DEV-06 | 点击状态按钮没有任何变化 | 点击事件使用比较表达式，而不是给状态赋值 | 改为更新 `activeStatus` |
| DEV-07 | Element Plus 表格或按钮属性不生效 | 动态属性缺少 `:`，并误写了 `*border*` | 使用 `:type` 和标准 `border` 属性 |

## 7. 测试结论

本轮 23 条功能用例全部通过，7 个已发现的功能缺陷均完成修复和回归。运营筛选联动、图表渲染、设备查询、工单增删改与持久化、数据查询及异常重试等主要流程运行正常。

当前测试基于本地 Mock 数据和浏览器 LocalStorage，尚未覆盖真实接口、多人并发、权限控制、跨浏览器兼容性及自动化回归测试。这些内容可在接入后端后继续补充。
